# GD VR Theater — Meta Quest 2

Небольшой сайт-кинотеатр на WebXR для просмотра локальных записей Geometry Dash на виртуальном экране.

## Что умеет
- работает как обычная веб-страница;
- может перейти в `immersive-vr` в совместимом браузере Meta Quest;
- позволяет выбрать локальный видеофайл и вывести его на виртуальный экран.

## Важно
Этот проект **не содержит Geometry Dash**, не устанавливает игру и не захватывает изображение из другого приложения Quest. Веб-страница не может напрямую читать экран отдельной игры. Для просмотра живого игрового процесса с ПК используй Meta Quest Link / Air Link или Virtual Desktop. Для просмотра записи выбери видеофайл на странице.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `gd-vr-theater`.
2. Загрузи `index.html`, `README.md` и `.nojekyll` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через некоторое время GitHub покажет адрес сайта вида `https://ТВОЙ-АККАУНТ.github.io/gd-vr-theater/`.

## Запуск на Quest 2
1. Открой опубликованный HTTPS-адрес в Meta Quest Browser.
2. Выбери видео MP4 (H.264) из файлов шлема.
3. Нажми «Воспроизвести видео».
4. Нажми «Открыть VR-кинотеатр» и подтверди вход в VR.

## Технологии
A-Frame 1.6.0 (подключается с CDN) и WebXR. Для VR нужен совместимый браузер и HTTPS.
