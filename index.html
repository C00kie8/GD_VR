Сначала выбери видео, затем открой VR-режим.

Поддерживаются локальные видеофайлы, например запись игрового процесса. Для лучшего результата используй MP4 (H.264) в формате 16:9.

Важно: сайт не устанавливает саму Geometry Dash и не может захватить изображение из отдельного приложения Quest. Он показывает на виртуальном экране выбранный видеофайл. Для трансляции живой игры с ПК используй Air Link или Virtual Desktop.
1. Открой сайтОпубликуй проект через GitHub Pages и открой ссылку в браузере Meta Quest 2.
2. Выбери записьНажми «Выбрать видео Geometry Dash» и выбери MP4 из файлов шлема.
3. Войди в VRНажми «Открыть VR-кинотеатр» и разреши переход в VR, если браузер спросит.
